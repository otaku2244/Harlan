# 部署手册：VPS 常驻 + 手机访问

> 面向"照着做就行"。每一步都有**验收方法**——做完能确认这步真的成功了，
> 而不是到最后才发现某个环节错了。

架构（先看懂这个，后面就不会迷）：

```
VPS（24 小时开机）              ← 服务常驻在这里
├── Serein（Docker，端口 18217）  ← 记忆
└── Harlan 后端（systemd，端口 8080）← 本项目
        ↑
        │ Tailscale 内网（100.x.x.x）
        │
   手机 = 客户端                  ← 只是屏幕，不开服务
```

**核心观念**：你**不需要在手机上启动任何服务**。
手机上只做两件事：用浏览器打开地址；以后装个壳收后台推送。

---

## 0. 先确认手机和 VPS 在同一个 Tailscale 网里

这一步不做，后面全白费。现象会是"服务在跑但手机连不上"。

```bash
# 在 VPS 上
tailscale status          # 应该能看到你自己和手机
tailscale ip -4           # ★ 记下这个 100.x.x.x，后面要用
```

**验收**：手机浏览器打开 `http://<VPS的100.x.x.x>:18217`，能看到 Serein 登录页。

> 连不上先别继续。检查：手机装 Tailscale 了吗？两边登录同一账号吗？
> Tailscale 不通的话，后面所有步骤都会失败，而且报错会很难懂。

---

## 1. 拉代码

```bash
cd ~
git clone https://github.com/otaku2244/Harlan.git harlan
cd harlan
```

**为什么用 `~/harlan` 这种纯英文路径**：中文路径在 Linux 上会带来一整类
编码麻烦（我们本机开发时就因为 `D:\AIchat\前后端` 这个中文路径踩过坑）。
VPS 上用纯 ASCII 路径能完全避开。

**验收**：`ls` 能看到 `app/`、`requirements.txt`、`启动.bat` 等。

---

## 2. 装依赖

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

**验收**：`python -c "import fastapi, httpx; print('ok')"` 输出 `ok`。

> ⚠️ 不要用 AionsHome 的 requirements.txt。那份含 `pywin32` / `sounddevice` /
> `opencv-python`，是 Windows 原生依赖，在 Linux 上装不上或跑不起来。

---

## 3. 写配置

```bash
cp .env.example .env
nano .env
```

**必须改的三处**：

```bash
AION_HOST=100.x.x.x        # ★ 你的 Tailscale IP，不是 127.0.0.1
AION_PORT=8080
SEREIN_BASE_URL=http://127.0.0.1:18217    # VPS 上是本机，用 127.0.0.1 最快
SEREIN_GATEWAY_KEY=<你的 Gateway Key>
MODEL_BASE_URL=http://127.0.0.1:18217/v1
MODEL_API_KEY=<同上 Key>
MODEL_NAME=deepseek/deepseek-flash
```

**⚠️ 最容易踩的坑**：`AION_HOST=127.0.0.1` 时服务只能本机访问，
你会遇到"服务明明在跑、VPS 上 curl 也通，但手机连不上"。
**记得填 Tailscale IP。**

**验收**：
```bash
python3 -c "
from app.config import settings
print('serein:', settings.serein_enabled)
print('model :', settings.model_enabled)
print('host  :', settings.host)
"
```
三项都应该是有值/True，`host` 应该是 `100.x.x.x`。

---

## 4. 先手动跑一次，确认真能工作

**这一步别跳。** 直接上 systemd 的话，出错了要看日志才能定位；先手动跑，
报错会直接打在屏幕上。

```bash
. .venv/bin/activate
python3 -m uvicorn app.main:app --host 100.x.x.x --port 8080
```

**验收**：另开一个终端（或手机浏览器）访问 `http://100.x.x.x:8080/healthz`，
应返回 `{"status":"ok", ...}` 且 `serein_configured: true`、`model_configured: true`。

再确认聊天能通：访问 `http://100.x.x.x:8080` → 打开聊天 → 发一句「你好」。

**确认没问题后按 Ctrl+C 停掉**，进入下一步做常驻。

---

## 5. 做成常驻服务（systemd）

这一步做完，**以后永远不用手动启动**，机器重启也会自己起来。

```bash
sudo nano /etc/systemd/system/harlan.service
```

内容（把 `YOUR_USER` 和 IP 换成你自己的）：

```ini
[Unit]
Description=Harlan backend
After=network-online.target tailscaled.service
Wants=network-online.target

[Service]
Type=simple
User=YOUR_USER
WorkingDirectory=/home/YOUR_USER/harlan
EnvironmentFile=/home/YOUR_USER/harlan/.env
ExecStart=/home/YOUR_USER/harlan/.venv/bin/uvicorn app.main:app --host 100.x.x.x --port 8080
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now harlan
```

**`enable` 是关键**——它让服务开机自启。之后你永远不用"启动"它。

**验收**：
```bash
systemctl status harlan          # 应显示 active (running)
curl http://127.0.0.1:8080/healthz
```

常用命令：

```bash
sudo systemctl restart harlan    # 改完配置重启
sudo systemctl stop harlan       # 临时停
journalctl -u harlan -f          # 看实时日志（排查必备）
```

---

## 6. 手机访问

**方式一（现在就能用）**：手机浏览器打开 `http://100.x.x.x:8080`

想要桌面图标 / 全屏观感：
- Chrome 菜单 → **添加到主屏幕**（PWA）
- 某些功能（如 `getUserMedia` 麦克风）在 HTTP 下不可用，
  需要 Chrome 的 `chrome://flags` 把该地址标记为安全源

**方式二（P2，还没做）**：Android 壳
- 好处：**后台推送**（不用一直开着浏览器）、原生麦克风/摄像头桥
- 需要：`LauncherActivity` + `WebViewActivity` + `AionPushService` 三件套
- 抄 AionsHome 的 14 条踩坑记录能省很多时间（`adb install -r` 才真的部署了 APK 等）

## 常见问题

| 现象 | 大概率原因 |
|---|---|
| 手机连不上，但 VPS 上 curl 通 | `AION_HOST` 绑了 `127.0.0.1`，改成 Tailscale IP |
| 手机连不上，VPS 上 curl 也不通 | systemd 没起来（`systemctl status harlan`）或 Tailscale 没通 |
| 服务起来了但没记忆 | `.env` 里 Serein 配置没读到 —— 用 `/healthz` 看 `serein_configured` |
| `/healthz` 显示配置全空 | 检查 `EnvironmentFile` 路径是否写对 |
| 聊天报"模型未配置" | `MODEL_*` 三项没填全 |
| 回复是空白的 | 上游模型间歇 502，已在代码里做退避重试；连续出现就看 `journalctl` |

## 本机 vs VPS 的区别（一张表）

| | 本机（你的 PC） | VPS |
|---|---|---|
| 用途 | 开发调试 | 长期运行 |
| 启动方式 | 双击 `启动.bat`（关掉就停） | systemd 常驻 + 开机自启 |
| 监听地址 | `127.0.0.1` | Tailscale `100.x.x.x` |
| 谁能访问 | 只有自己 | 你的手机、PC（同一 Tailscale 网内） |
| 停止 | 关窗口 / Ctrl+C | `systemctl stop harlan` |

**本机不需要 24 小时开着。** 手机要连的是 VPS 那个。
